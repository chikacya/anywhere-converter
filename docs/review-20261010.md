# 本地更新与验证报告（2026-10-10）

范围见 [执行计划](update-plan-20261010.md)。基线 converter 64f5797、Anywhere ea12a6e5（2.4/397）。本轮没有提交、推送、部署，也没有修改 Anywhere 或正式 MITM 产物。

## 已落实

1. 完整 AST 白名单：请求和响应提升不再遗漏未知操作；根字段赋值用 add、保留顺序；复杂条件/过滤/嵌套/递归保留完整 JS。不安全的请求 head 修改明确阻止。query redirect / URL proxy 保留原始条件和响应参数。
2. 工坊发布副本内存 TTL；响应缓存不能重新延长即将过期的旧副本；条件请求返回 304 和正确 Age。跨实例更新/删除测试通过，正常订阅读取未新增 DO 调用。KV 的分布式传播延迟仍存在；不承诺全球瞬时一致或刷新零额度消耗。
3. URL/searchParams 常用读写联动、host/origin 联动及默认端口处理。无原生 timer 不伪造正延时；复杂 URL 与 timer 有明确诊断。
4. 静态 runner、同源参数共享、按需正文解码、正文脚本小型适配器、依序 await、异常二进制透传。正确重命名顶层 process，不误改上游嵌套函数。补 globalThis.$argument、平台环境及 $script，并在子脚本结束后恢复全局。
5. 可选 AMOD：CLI --output-format amod、API outputFormat、UI、动态订阅、快照、一键导入均接通；默认独立文件不变。子集名稳定、保留参数与路由初始值。超过预算回退全部独立文件，不裁规则。拆分动态文件增加 part 索引，避免多链接指向同一首段。
6. 可复现验证入口与模式/映射说明更新；原网易云 golden 明确是合成参数格式测试，另加真实源码行为验证，不上传上游 fixtures。

## 验证

- npm test：116 项完整回归通过、0 失败、0 跳过；真实网易云测试使用本地锁定快照，无快照时显式 skip。
- verify-native-json：直接编译当前 APP 的 MITMJSONPatch 和原生 operation enum。12 个输入：8 个普通对象结构对照、2 个无效 JSON 透传、2 个大整数差异。结构比较通过；普通对象中 4 个输出存在字节格式差异。原生保留 9007199254740993，JS 会舍入为 9007199254740992，所以原生 JSON 提升输出需验证标记，不声称字节等价。
- 真实网易云：MY=0/1 的运行时参数控制漫游标签；用 Node AES-ECB 解密转换结果检查标题；无效二进制透传。没有替换上游加密实现。
- Worker：模拟两个隔离实例、共享 KV/DO；更新、删除、TTL 即将到期、ETag、Age；AMOD 动态/快照链接及 deep link。
- UI 内联 JavaScript 语法检查、本地 Wrangler health/HTML、Worker dry-run 打包通过。不是 iPhone 操作或 Anywhere 原生 AMOD 导入的实机验收。

## 保留的边界

- AMOD 上限按源码：64 个子集、每 MITM 10,000 条/256 参数、每 Routing 100,000 条、模块图标 65,536 字节、编码模型 900,000 字节。当前采用包含字符串转义与模型开销的保守预算，不模拟整个 Swift JSONEncoder；可能提前回退。没有声称按 AMOD 文本长度即可算出原生模型大小。
- URL shim 不是完整 WHATWG；复杂路径、百分号容错、迭代器等仍需针对样本处理。高级编码/crypto.subtle/XMLHttpRequest/stream-script 不猜映射。
- 自适应 wrapper 不剥离上游 APP 逻辑、Protobuf schema、加密库。新增 AST 检查增加转换 CPU；Worker dry-run 不能证明生产 Free Plan CPU/账单，部署后的真实配额须另行观察。本轮没有提高远程抓取预算或添加订阅常态 DO 读取。
- npm audit 报告现有开发工具链 Wrangler/Miniflare/Sharp/Undici 的 4 个 high 项。本轮新增 Acorn 无此项报告；未混入 Wrangler 升级或 audit fix。生产依赖更新需单独验证。
