# 通用转换器更新计划（2026-10-10）

基线：converter 64f5797；Anywhere ea12a6e5，2.4(397)。只改转换器；正式 MITM、Anywhere 源码与精确上游快照只读。本轮本地交付，不提交/推送/部署。

## 顺序与验收

1. 转换正确性：用 AST 检查完整脚本；所有操作均可表达才原生化。保留语句顺序；缺失字段赋值不再误用 replace；正则只转换可证明等价的 flags、全局替换、捕获模板。无法证明时保留 JS。验证正常、缺失路径、未知操作、条件、正则反例及重叠规则。
2. 工坊缓存：发布副本内存缓存设置 TTL、过期重新读 KV；不新增订阅 DO 调用。多 Worker 实例共享 KV/DO 的行为测试覆盖更新、删除、条件请求与缓存到期。
3. 兼容层：修正 URL/searchParams 常用读写联动；未知 API 给出明确诊断。没有原生 timer 时不伪造延时，保留零延时微任务并对真实延时/重复 timer 明确报错与诊断。隔离 VM 不注入 URL/timer 验证。
4. 运行成本：静态 runner 避免转换器自身的 Function 编译；同源不同参数共享 runner；正文按需解码；合并 dispatcher 正确 await 子脚本。不删 APP 专用逻辑/schema。验证异步顺序、异常、二进制透传及总 JS/单次 JS 指标。
5. AMOD：可选输出，默认仍为 AMRS/ARRS；CLI、API、UI、动态订阅与一键导入完整接通。按实际原生解析/模型约束验证 64 个子集、64 KiB 图标、900,000 字节编码 JSON；超过预算保留独立文件并说明。稳定子集名称，保留参数和路由初始值。
6. 验证与文档：完整测试，实际 Swift JSON 原生实现对照，锁定正式样本离线转换（网易云、Spotify、小红书、Bilibili、YouTube、Pixiv、航旅纵横），记录可用/跳过与前后成本。现有 golden 明确为参数测试，并增加真实来源本地验证入口；不把合成回归视为实机通过。
